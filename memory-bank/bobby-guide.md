# 给 Bobby 的产品说明

这套方案不改变你现在的一对一求职咨询业务，只是把找人、约时间、收材料、发会议和查订单这些重复沟通集中到一个小程序里。

## 建议这样看

1. 从首页走一遍搜索、查看资料、选择时间、提交简历和问题的预约流程。
2. 切换到咨询工作台，查看预约材料、会议、改期和个人资料填写。
3. 最后查看波比后台，了解资料、档期、订单、会议、退款和线下结算如何集中管理。

## 它主要解决什么

- 投稿编号、学校和岗位方向可以直接搜索，找人更快。
- 可约时间、时长和价格直接展示，减少来回确认。
- 简历和问题在预约时一次收齐。
- 订单、会议、退款和结算集中管理，方便运营和统计。

## 这次希望确认

1. 整体流程是否符合现在真实的咨询业务。
2. 十位投稿资料的展示和搜索方式是否合适。
3. 如果继续做，是否愿意一起确定运营规则和首批资料。

当前页面用于一起确认产品方向。支付、上传、通知和会议不会真正触发；正式合作后，再按生产方案接入微信小程序、微信支付和相关服务。
