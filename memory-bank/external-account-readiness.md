## 4. 推荐办理顺序

1. 先向所在地人力资源社会保障部门和市场监督管理登记窗口描述真实业务，确认属于就业指导/人力资源管理咨询备案，还是职业中介许可，以及个体工商户能否承接；不得通过弱化业务描述规避许可。
2. 根据答复确定经营主体。以当前多前辈平台收款、80%/20%结算、未来群面讲座的规模，默认推荐有限公司；若当地明确允许个体工商户且波比只做低成本试运营，再比较个体工商户方案。
3. 主体注册完成后，以同一主体注册并认证微信小程序，选择与真实服务一致的类目，完成小程序备案并为技术负责人分配开发权限。
4. 申请微信支付普通商户号，开通小程序支付/退款能力并绑定小程序 AppID；真实密钥只进入安全配置。
5. 主体名称稳定后购买域名并完成同主体实名认证；生产发布前完成 ICP 备案和 HTTPS。CloudBase 默认域名只用于开发测试。
6. 小程序类目确定后申请订阅消息模板；先准备支付、会议更新、改期、退款和咨询提醒五类模板文案。
7. 腾讯会议个人版只用于不并发的内部测试。公开上线前按预计同时咨询数购买/配置足够会议房间，或正式确认由每位咨询提供方使用自己的会议账号并同步修改运营流程。
8. 腾讯云暂不急着购买全部生产资源；先验证实名账号可创建 CAM 身份和账单告警，代码骨架稳定后再按实施步骤建立隔离环境。
