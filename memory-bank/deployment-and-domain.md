## Demo 阶段的建议

现在不需要购买域名，也不需要为 Demo 单独购买服务器或办理备案。先把现有链接发给 Bobby，验证三件事：

1. Bobby 是否认可产品方向。
2. 当前业务流程和页面是否符合实际运营。
3. 双方是否愿意继续投入时间和资源。

只有第三点确认后，再决定域名、主体、小程序和支付等生产准备。

## 正式合作后的域名方案

### 1. 先确定域名归属

域名应注册在未来长期运营这个项目的个人或企业主体名下。若品牌和业务主要属于 Bobby，不建议由开发者个人长期持有域名，以免以后发生转移、续费或权限问题。

### 2. 注册域名并实名认证

可优先考虑简短、容易口述、与 Bobby 或求职咨询相关的 `.com` 域名。正式注册前需要查询实时可用性。注册时使用真实、可长期维护的联系人、手机号和邮箱，并完成域名实名认证。

### 3. 预留清晰的子域名

- `demo.example.com`：产品演示和测试。
- `www.example.com`：以后的网站或品牌首页。
- 小程序接口域名可在生产技术方案确定后另行规划，不要为 Demo 提前创建复杂域名结构。

### 4. 决定服务器地域后再办理备案

- 如果网站部署在中国大陆服务器，必须先完成 ICP 备案，取得备案号后再开放访问。
- 如果使用中国香港或其他境外服务器，通常不需要 ICP 备案，但中国大陆访问速度和稳定性需要单独评估。
- 若选择腾讯云中国大陆资源，备案主体、域名实名主体和实际运营主体应尽量保持一致，并按所在省份管局要求准备资料。

### 5. 最后绑定解析与 HTTPS

托管平台确定后，再按平台提供的记录配置 DNS。通常为给子域名添加 CNAME 或其他验证记录；平台验证成功后签发 HTTPS 证书。不要在托管平台尚未确定时频繁修改域名解析。

## 推荐决策

当前阶段先使用两条 Vercel 链接向 Bobby 展示产品提案和完整原型，不购买服务器、不办理备案。妙搭重新发布当前快照后，可再作为中国大陆备用入口。若 Bobby 确认合作，再由双方先确定运营主体和域名归属；随后注册域名，并在生产部署地域确定后决定是否走中国大陆 ICP 备案。

Vercel 链接用于海外访问、作品集和备用展示；Vercel 官方不保证中国大陆的访问稳定性，因此不能替代妙搭国内链接。
