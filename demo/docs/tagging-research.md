# 演示资料标签研究与归一记录

> 更新日期：2026-08-27  
> 目的：解释本轮 10 条公开投稿如何从行业简称转成可检索标签；不是对个人经历的证明核验。

## 1. 处理原则

1. 原始术语与标准标签同时保留，展示事实和检索用途分离。
2. “过简历、进入一面/终面、获得 Offer、暑期留用”分别记录，不合并为“拿到 Offer”。
3. 能确认含义的行业简称才归一；公司内部简称或学校层次不明确时保留原文。
4. 户籍类内容不进入字段；性别和政治面貌不参与搜索排序。
5. `Top`、`头部`、`三中一华` 等相对或匿名表述按原帖保留，不反推具体学校或公司。

## 2. 重点术语

| 原词 | 演示版处理 | 理由 |
| --- | --- | --- |
| 金租 | 标准标签“金融租赁” | 国家金融监督管理总局将金融租赁公司定义为经批准设立、以融资租赁为主的非银行金融机构。 |
| 金租前台 | 标准标签“金融租赁”＋原词“前台岗” | CFA Institute 将金融业 front office 概括为直接面向客户和创收的活动；这里不是软件前端开发。 |
| 公募机销 | 标准标签“公募基金机构销售” | 结合帖子“券商机销”和最终去向，语境是面向机构客户的基金销售；“公募基金销售”本身受证监会规则约束。 |
| PMO | 标准标签“项目管理 PMO” | PMI 将 PMO 描述为集中、协调或支持项目与项目集管理的组织实体；不同公司的职责仍需结合原岗理解。 |
| PIM | 只保留“PIM（原文）” | PIM 可指产品信息管理，也可能是企业内部岗位简称；帖子缺少 Shopee 内部定义，不能擅自展开。 |
| IB | 标准标签“券商投资银行” | CFA Institute 对 investment banking 的说明包括融资、并购和企业财务顾问等活动。 |
| 行研 / 卖方行研 | 标准标签“券商行业研究” | 与帖子里的券商研究所、卖方研究语境一致。 |
| 商分 | 标准标签“商业分析” | 与大厂商业分析岗位语境一致，不等同于数据科学或财务分析。 |
| 产运 | 标准标签“产品运营” | 与“中台产运”“产品/产运运营”的原帖上下文一致。 |
| 管培 / MT | 标准标签“管理培训生” | 表示培养项目或招聘项目，不自动推断具体业务条线。 |
| SP / SSP | 只保留招聘结果原词 | 表示企业校招 Offer 等级或人才档位，不是岗位类别，不参与岗位检索。 |
| 中九 / Top4 / top 美硕 / 港五硕 | 保留原词；仅在可安全概括时增加粗粒度标签 | 这些不是统一公开标准。“中九”按项目既有字典映射为中流 985；其余不强行映射为精确排名。 |
