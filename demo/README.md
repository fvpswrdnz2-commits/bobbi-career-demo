# 熬夜波比 Bobby 产品沟通包（方案 B）

这是用于和 Bobby 对齐产品方向的高保真 H5，不是正式小程序，也不会产生真实支付、文件上传、通知、会议或结算。

## 打开方式

- 同一小程序双身份：直接双击 `index.html`。
- 波比独立运营后台：直接双击 `admin.html`。
- 本地服务：在 `demo/` 目录启动任意静态文件服务后打开首页。

## 建议演示顺序

1. 首页说明统一算法列表，没有“精选”和“最近上新”。
2. 依次搜索 `投稿354号`、`PMO`、`金租`、`公募机销` 或 `AI 产品`，展示编号直达、别名理解和匹配理由。
3. 打开一条资料，核对教育、实习、秋招情况、Offer、心得和独立档期。
4. 选择时间，选择任意本地测试文件，填写至少 10 个字的问题。
5. 走过支付确认，展示“会议链接稍后更新，请在咨询开始前查看”。
6. 从“我的”进入咨询工作台，查看资料填写、咨询详情、改期和取消。
7. 打开 `admin.html`，查看资料、档期、订单、会议、退款、结算和经营数据。

## 数据与隐私

- 数据源为用户提供的 Bobby 小红书公开投稿截图。
- 首批 10 条：354、353、352、351、350、349、348、347、345、344；343 留作候补。
- 公开昵称根据投稿标题整理，不代表真实姓名。
- 历史帖子按“旧资料导入、证明材料豁免”标记；没有做证明核验。
- 户籍类信息不进入数据；政治面貌和性别只保留为原帖背景，不参与排序。

## 检查

运行 `node tests/check.mjs` 可检查资料数量、投稿编号、关键术语防误标、隐私边界、移动端流程、10 个后台页面和已确认文案。逐页覆盖情况见 `memory-bank/demo-page-coverage.md`。
