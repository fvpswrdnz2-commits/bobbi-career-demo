# 熬夜波比全页面原型

这是当前用于和 Bobby 沟通的高保真页面原型，覆盖预约咨询、提供咨询和波比后台共 27 个业务页面。产品界面不展示“演示”或“模拟”说明。

## 查看方式

1. 在本目录运行 `npm start`。
2. 浏览器打开 `http://127.0.0.1:4173`。
3. 默认从预约咨询首页进入；顶部只保留“预约咨询”“提供咨询”“波比后台”三个菜单，可通过左侧目录逐页查看。向 Bobby 展示时点击“专注预览”，界面会隐藏原型目录和页面说明。

页面内主要按钮、搜索、时长、档期和身份切换均可点击。十位历史投稿资料由 `demo/data/` 的结构化公开数据提供。

## 检查

运行 `npm run check`，会检查脚本语法、页面数量、页面跳转目标和主要 HTML 结构。
